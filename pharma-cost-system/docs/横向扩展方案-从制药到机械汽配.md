# 横向扩展方案：从制药成本分析到机械 / 汽配 / 化工 / 电子制造

> **文档性质**：行业迁移设计说明，对应《赛题原文-创灵境赛道》第 186 行"横向扩展说明"加分项。
> **基线系统**：`01_源代码/pharma-cost-system`（FastAPI + RAG + 大模型 + RPA，已贯通赛题四大模块）。
> **约定**：写"已实现"的内容均可在代码中定位；写"配置化 / 需改造 / 需新建"的均为迁移建议，**尚未在真实离散制造数据上验证**。

## 一、结论摘要

系统的可迁移资产不是"中药成本报表"，而是四条与行业无关的流水线：**数据层** `data_service.py`/`period.py`（算法无关，字段与单位强相关）、**知识层** `rag.py`（jieba + BM25 与向量混合检索，文档强相关）、**生成层** `report_model.py`/`report_gen.py`/`pdf_export.py`/`charts.py`（引擎无关，模板与提示词强相关）、**闭环层** `rca.py`/`benchmark.py`/`rpa.py`/`forecast.py`（方法无关，责任人库与任务模板强相关）。

**总体复用度：约 60% 可原样复用，25% 需配置化或轻度改造，15% 需新建。** 改造集中在"投入侧语义"：成本对象层级（产品 → 工单/工序）、计量单位（元/盒 → 元/件·工序）、知识文档与提示词、RPA 任务模板；**算法公式、图表渲染、Word/PDF 双导出引擎无需重写**。

## 五、指标与模型改造点

### 5.1 单位成本口径：元/盒 → 元/件·工序

| 环节 | 现状（已实现） | 目标 | 改动方式 |
|---|---|---|---|
| 计量单位 | "元/盒""产量(盒)" | "元/件·工序""合格产出(件)" | 单位与字段名配置化 |
| 成本对象键 | 月份 × 产品（`_find`） | 月份 × 产品 × 工单 × 工序 | 维度键扩展 + 下钻 |
| 加权权重 | `产量(盒)` | 合格产出量（剔除废品/返修） | 权重字段替换 |
| 聚合算法 | `agg_row`：Σ(单位量×产量)/Σ产量 | 同左 | **零改动** |

### 5.2 为什么环比 / 同比 / 预算偏差 / 贡献度公式不变

- 三个比率同出一个算子 `DataService._rate(cur, base) = (cur − base) / base × 100`，是**无量纲比率**，与量纲是盒、件、吨还是吨·工序无关；
- 贡献度 = 要素单位成本变动额 ÷ 单位成本总变动额（`dv / duc`），分子分母同量纲，**比值恒成立**；
- 周期聚合是"单位量 × 权重"的加权平均，只要求**权重可加、单位一致**，合格产出量同样可加。

因此 `period.py` 与 `kpi_overview` 的**公式层零改动复用**，改造面仅限字段映射、单位与成本对象层级。

### 5.3 标准成本 vs 实际成本：价差 / 量差 / 结构差的等价映射

| 差异类型 | 制药口径（本项目现状） | 离散制造等价映射 | 已有基础 / 改造建议 |
|---|---|---|---|
| 价差 | 药材采购单价变动（`material_diff` 的 `单价变动`，取自行情表） | 钢材/外购件/粒子实际单价 vs 标准单价 | 已有单价信息；**建议新建** PV =（实际单价 − 标准单价）× 实际用量 |
| 量差 | 单位消耗成本变动（`单耗变动`，对应收率） | BOM 用量、材料利用率、刀具消耗 vs 标准用量 | 已有单耗信息；**建议新建** UV =（实际用量 − 标准用量）× 标准单价 |
| 结构差 | 品种结构、自采比例差异 | 工单结构、产品结构、自采/外协比例导致的加权单位成本漂移 | 现由对标"拆结构"近似覆盖；**建议新建**专项表 |
| 人工差异 | 时薪（工资率）× 工时_万盒（效率）两个派生量 | 工资率差 + 效率差（元/工时、工时/件） | 已有派生量，**建议双因子分解** |
| 制造费用差异 | `_oh_explain`"折旧固定，产量下降导致单位摊薄上升" | 耗费差 + 产能利用（产量）差 | `_topic_text` 已区分固定/变动，建议分别归因 |

**关键判断**：本项目现为"价、量指标并列呈现"，尚未做 PV/UV 乘法桥接与瀑布分解——这是迁移离散制造时**最值得新增的模块**。

## 八、风险与边界

| 风险 | 具体表现 | 应对建议 |
|---|---|---|
| 数据质量 | BOM 不准、工时台账缺失、工序报工不完整 → 量差与效率差失真 | 先做数据体检（完备率、口径一致性、BOM 版本唯一性）；工序缺失回退产品级 |
| 模型幻觉 | 归因/对标文本由大模型生成，可能无依据 | 已有三重约束：RAG 上下文（`rag.context` 带来源）、无 Key 降级 `rule_based_rca`、报告附录 RAG 命中片段表可追溯；**建议新增**人工复核签核 |
| 权限与保密 | 成本数据敏感；`main.py` 无鉴权，接口默认开放，仅适用本机演示 | 生产需角色分权、字段脱敏与水印；赛题原文已明确保密要求 |

| 口径漂移 | 阈值固定 ±10%，多品种多工序下误报/漏报 | 阈值规则表 + 分品种基线 + 滚动中位数 |
| 边界声明 | 本方案结论为**设计推演**，未在真实机械/汽配/化工数据上运行 | 落地前须完成真实客户的字段映射与对账 |
